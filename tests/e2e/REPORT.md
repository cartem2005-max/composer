# Тесты интерфейса (Playwright)

Запуск: `npm run e2e` или `npx playwright test --retries=0 --reporter=list`. Браузер — установленный Chrome (`channel: 'chrome'`), браузеры Playwright не скачиваются. Запрос `/api/pick` во всех тестах подменён — настоящий ИИ не вызывается.

Экспорт проверяется разбором файла: нет `<image>`, `<script>`, `href`, `data:`; id уникальны; единственная ссылка `url(#…)` — обрезка по кадру; размеры соответствуют формату; цвета только из текущей схемы.

Найденные тестами и исправленные баги (тесты на них остались как регрессионные):
1. Повтор номеров объектов после «Собрать» — «Удалить» убирало два объекта.
2. Ползунок «Поворот» терял фокус после каждого шага.
3. Свои палитры с одинаковыми первыми цветами затирали друг друга.
4. Управляющие символы в имени палитры ломали XML экспорта.
